# PRD - Sistema Integral Financiero Educativo (SIFE)

## 1. Visión General
**SIFE** es una solución tecnológica diseñada para modernizar la gestión financiera de instituciones educativas. Su objetivo principal es eliminar la carga operativa de las secretarías administrativas mediante la automatización de la conciliación de pagos.

## 2. Objetivos del Producto
- **Automatización:** Reducir a cero la validación manual de comprobantes de pago (WhatsApp/Email).
- **Conversión:** Atraer y convertir directivos mediante una landing page profesional y persuasiva.
- **Confiabilidad:** Transmitir orden, seguridad y modernidad administrativa.

## 3. Público Objetivo
- **Directores de Instituciones:** Buscan rentabilidad y control financiero.
- **Secretarios Administrativos:** Sufren la carga operativa diaria de la conciliación manual.
- **Padres/Tutores:** Usuarios finales que interactúan con la plataforma de pagos.

## 4. Características Principales (MVP)
- **Landing Page de Alta Conversión:** Secciones de Hero, Problema/Solución, Características y Testimonios.
- **Conciliación Automática:** Integración vía API para validación inmediata de pagos (CBU/CVU).
- **Formulario de Captación:** Validación rigurosa para solicitudes de demo (Email institucional, teléfono, nombre de la escuela).
- **Diseño Responsive:** Optimización total para dispositivos móviles.

## 5. Requisitos de Experiencia de Usuario (UX)
- **Claridad Administrativa:** Uso intensivo de espacios en blanco y tipografía legible (Inter).
- **Estética "Clean":** Paleta de colores basada en `slate-50` y `blue-600` para transmitir profesionalismo.
- **Velocidad:** Tiempos de carga mínimos gracias a Turbopack y optimización de imágenes.

## 6. Métricas de Éxito
- Tasa de conversión del formulario de demo.
- Tiempo promedio de permanencia en la landing.
- Desempeño en Core Web Vitals (LCP, CLS, FID).


## 7. Puntos de Valor de SIFE

- Demo de un curso para probar funcionalidades gratis
- cobro del servicio, instalacion, capacitacion y mesa de ayuda mediante 1% de las cuotas
- solo cobro de cuotas
- permite configurar cualquier tipo de de cobro, inscripcion, materiales, talleres, excursiones, donaciones, entradas de eventos, etc.
- Permite tener una vista personnalizada para padre y para adminsitración
