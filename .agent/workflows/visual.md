## 1. Identidad de Color
- **Fondo:** `bg-slate-50` (Aporta limpieza y profundidad).
- **Textos:** `text-slate-900` para títulos, `text-slate-600` para descripciones.
- **Botones Primarios (CTAs):** `bg-blue-600` con `hover:bg-blue-700` y `text-white`.
- **Acentos:** `indigo-500` para destacar badges de "Nuevo" o "API Ready".

## 2. Tipografía e Iconos
- **Fuente:** Inter (Sans-serif moderna).
- **Iconografía:** Lucide React (Stroke: 1.5px). Usar iconos que evoquen orden: `Table`, `FileCheck`, `ShieldCheck`, `Zap`.

## 3. Estética de Componentes
- **Bordes:** `border-slate-200`.
- **Sombras:** `shadow-sm` para cards, para evitar que parezca "pesado" o antiguo.
- **Layout:** Uso intensivo de White Space (espacio en blanco) para transmitir claridad administrativa.
